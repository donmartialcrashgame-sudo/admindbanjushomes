Quick help
1. Set upGive the page a title, choose a sidebar category, add an introduction and choose an icon.
2. Add blocksSelect any block tool. Fill its fields and the preview updates as you work.
3. ArrangeUse ↑ ↓ to move blocks, duplicate to reuse a block, and the bin icon to remove one.
4. Save and openSave adds a sidebar link and opens the new page. Export JSON for a backup.
5. Command toolsType commands like add table, add notice, preview, export, undo or clear.
6. ImportantPages and custom sidebar links are saved in this browser's local storage, not shared to other browsers or computers.
